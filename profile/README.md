## what is bitPOS

bitPOS is a hosted Lightning point of sale — merchant dashboard, tap-to-pay terminal (posBOX), NFC Bolt Cards — settled over NIP-47 Nostr Wallet Connect against **the merchant's own wallet**.

bitPOS does not take custody of merchant funds. **1% on incoming payments. Outgoing is free.**

The source is public so you can verify what `bitpos.app` runs. This is not a self-host kit.

| Project | What it is |
|---------|------------|
| [`bitPOS-app/bitpos`](https://github.com/bitPOS-app/bitpos) | The published source: API, web app, landing, posBOX firmware, card writer. |
| [`bitPOS-app/.github`](https://github.com/bitPOS-app/.github) | This profile + the published verification fingerprint. |
